I work across the entire product:

- **Back-end:** NestJS, TypeScript, Prisma and PostgreSQL

- **Infrastructure:** Docker

### 🎧 Manttarph

My Software Engineering capstone project at INATEL, **awarded the highest grade**.

Manttarph is an accessible RPG designed for people with visual impairments, where gameplay interaction happens through **audio and Text-to-Speech (TTS)**.

Built with **Python**, the project uses:

- Event-Driven Architecture
- MVCS
- Entity Component System (ECS)
- Node-based world navigation
- Battle system
- Inventory and trading systems
- Audio-based gameplay interaction
